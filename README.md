# Module 04 — Docker & Containerization

**Internship Project | Codomax Digital Solution**  
**Submitted By: Sikandar Shah**

This project demonstrates the practical implementation of Docker and containerization. A Python Flask web application was containerized using a Dockerfile and Docker Image, then deployed as a Docker Container. PostgreSQL was integrated using Docker Compose, with container networking, persistent volumes, environment variables, and database connectivity testing.

The project also includes Dockerfile optimization using a lightweight base image, `.dockerignore`, dependency caching, and efficient package installation.

### Technologies
Docker • Docker Compose • Python • Flask • PostgreSQL • WSL 2
